# Personal Finance Tracker

Personal finance management tool developed in Microsoft Excel with VBA macros to automate income, expenses and savings tracking.

---

## Overview

This project was designed to simplify personal financial management through automation.

The workbook allows users to register income and expenses, monitor savings and visualise financial information through interactive dashboards.

Main features include:

- Income and expense tracking
- Savings monitoring
- Automated calculations
- Interactive dashboards
- VBA automation

---

## Technologies

- Microsoft Excel
- VBA (Visual Basic for Applications)
- Pivot Tables
- Charts
- Financial Analysis
